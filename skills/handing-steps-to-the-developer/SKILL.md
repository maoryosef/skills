name: handing-steps-to-the-developer
description: Use when you give the developer commands or steps to run by hand, such as a bootstrap, an apply, an install or a step after a merge.
---
For each step, say what it does in one plain sentence, when it runs (before or after the command that prompts them, or after which event, such as a deploy job turning green), what to run, and what output means it worked.
List every prerequisite a fresh checkout lacks, such as a build output git does not track, before the command that needs it.
