# Sending review fixes
When you list what you will do after the go-ahead, include a Slack DM to each reviewer whose comments you fixed, next to the commit, the push, the PR body update and the thread replies.
After the go-ahead, send the DM last. It names the PR link, the comments that are fixed, and plainly what is still open.
