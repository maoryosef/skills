---
name: pointing-to-a-worker-terminal
description: Use when you ask the developer to approve, answer or type something in a worker's Superset terminal.
---
Before you ask, list and read every terminal of that workspace, so you know which one waits and what the others will say if asked.
Name the workspace as Superset shows it, the terminal tab by its position (first, second), and the last line that terminal shows, and say which other tabs in that workspace need nothing.
Name the branch Superset will show now, if a worker checked out another branch in that worktree.
